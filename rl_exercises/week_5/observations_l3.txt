DISCUSSION
----------

In the plots it can be seen that DDPG generally has a more stable training process.
The DDPG standard deviation is smaller with fewer outliers than REINFORCE's trainig process (view pg2.png and pg3.png in particular).
This is the expected outcome.
DDPG uses the Actor-Critic architecture, which makes it possible for the actor to learn from the evaluations made by the critic.
The critic filters noise from the environment by calculating the expected long-term values instead of the current volatile rewards.

REINFORCE only has the volatile rewards from each episode to work with.
This is especially difficult when dealing with environments such as LunarLander, because rewards are sparse, 
meaning they are only attainable when performing certain sequences of actions.
Thus, REINFORCE, acting stochastically, sometimes achieves high rewards, sometimes it doesn't.
DDPG doesn't have the same problem (not as much at least) and is able to find the sparse rewards in a more efficient manner.

Further, DDPG uses Target-Networks for both the actor and the critic.
When calculating the next Q-value, both can be used as a more stable baseline for calculation,
because these "copies" keep very bad or very good episodes from taking too much influence on the Q-update. (we used τ = 0.001)
